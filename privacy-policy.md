# Zovo Themer Privacy Policy

Effective: September 2, 2026

Zovo Themer does not use analytics, advertising, tracking pixels or telemetry.
It does not sell personal information.

## Data stored on your device

The extension stores site hostnames, visual theme settings, picked CSS
selectors, generated rules, the optional license key and a time-limited license
validation cache in Chrome local extension storage. This data supports the
extension's user-facing functionality and remains on the device unless Chrome
sync or browser backup behavior outside the extension copies it.

## Network activity

Zovo Themer does not transmit browsing history or theme profiles. When a user
explicitly submits a license key, the extension sends that key and the product
identifier `zovothemer` to the Zovo license verification endpoint hosted on
Supabase. The response is used only to decide whether Pro features are active.
The extension may use normal network requests required by the retained
userstyle installation and optional sync features when a user invokes them.

## Permissions

Access to websites is required to apply the selected visual changes on those
pages. Storage is required to remember profiles and styles. Tabs, scripting and
navigation access support applying changes to the correct page and the
point-and-click selector. Context menus and alarms support retained style
management features.

## Retention and control

Theme profiles remain until the user removes them or clears extension data. A
license can be removed from the device in the extension. Uninstalling the
extension instructs Chrome to remove its local extension storage.

## Contact

Privacy questions can be sent through https://zovo.one/.
